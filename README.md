# SSU:PICK

## 프로젝트 소개

숭실대학교 모바일프로그래밍 팀 프로젝트

SSU:PICK은 대학생에게 필요한 교내 공지사항,
취업 정보, 청년 지원 정책 및 주거 지원 정보를
한곳에서 확인할 수 있도록 제공하는 통합 정보 앱입니다.

## 주요 기능

- 교내 공지사항 및 취업 정보 제공
- 청년 지원 정책 정보 제공
- LH 및 마이홈 공공주택 정보 제공
- 사용자 프로필 기반 맞춤형 정보 제공
- 관심 정보 및 혜택 확인

## 기술 스택

- Android Studio
- Java / XML
- Python
- FastAPI
- AWS
- 공공데이터 Open API
- Git / GitHub

## 팀 정보

- 소속: 숭실대학교
- 과목: 모바일프로그래밍
- 팀명: 오대강
- 팀원: 전평강, 오정민, 김대원
